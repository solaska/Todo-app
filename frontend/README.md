# PERN Todo App

A full-stack Todo application built using the PERN stack (PostgreSQL, Express.js, React, Node.js).  
The application allows users to create, read, update, and delete tasks while demonstrating full CRUD operations, REST API architecture, database integration, and deployment workflows.

## Features

- Create new todos
- Read all todos
- Update existing todos
- Delete todos
- RESTful API architecture
- PostgreSQL database integration
- Full-stack deployment
- Environment variable configuration

---

## Deployment

The application is deployed using Render and connected to a Neon PostgreSQL cloud database.
